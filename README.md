# My Personal Portfolio 

Hey! Thanks for checking out my repo. This is the source code for my personal portfolio website, where I keep track of my projects, tech stack, and what I've been working on lately.

Built mainly to have a clean, fast space to showcase my work as a Full-Stack Engineer.

## Tech used here
- React & TypeScript (the usual)
- Tailwind CSS for styling
- Framer Motion for some of the animations
- Vite as the bundler

## Running it locally

Pretty standard setup if you want to run it yourself:

```bash
npm install
npm run dev
```

That's it. Feel free to explore the code. If you want to chat or collaborate, my socials are on the live site!
